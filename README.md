## 📱 Descripción

Aplicación móvil destinada a la gestión y consulta de información
académica de estudiantes.

## 👥 Usuarios

- 👨‍👩‍👧 **Padres:** consulta de información y notas.
- 👨‍🏫 **Profesores:** consulta y gestión de notas.

## 🔥 Base de datos

El proyecto utiliza Firebase Realtime Database.
